Sobre o UrbanJungle Helper

O UrbanJungle Helper é uma aplicação web client-side projetada para ajudar entusiastas de plantas domésticas a organizarem suas rotinas de rega, adubação e poda sem complicações.

Todos os dados são armazenados diretamente no seu navegador por meio da API de LocalStorage, garantindo rapidez, privacidade e funcionamento offline.

Guia Passo a Passo de Como Usar

  1. 1. Cadastre suas plantas

    Acesse a página Nova Planta ou consulte a Enciclopédia para preencher o nome, espécie, intervalo de rega em dias e data da última hidratação.

  2. 2. Acompanhe o Dashboard e o Cronograma

    No Dashboard você visualiza imediatamente quais vasos precisam de água hoje. No Cronograma, confira as previsões da semana.

  3. 3. Marque tarefas e evolua seu Jardim

    Registre cada cuidado nas páginas de Tarefas ou Perfil da Planta para manter sua ofensiva em dia e subir de nível em Jardim.

  4. 4. Faça backups periódicos

    Use a página de Configurações para exportar seus dados em JSON sempre que desejar guardar uma cópia de segurança.

Perguntas Frequentes (FAQ)

Meus dados somem se eu fechar o navegador?

Não. Os dados ficam persistidos no LocalStorage do seu navegador até que você limpe os dados de navegação ou use a opção de limpeza nas Configurações.

Como a próxima rega é calculada?

O sistema soma a frequência em dias definida no cadastro à data da última rega registrada para aquela planta.
